## 极限

### 一、定义

#### 1.1、$\lim_{x \to a} f(x) = L$
 - 表示当x无限接近a的时候，f（x）无限接近常数L
 - 注意：函数在x = a 处可以没有定义，极限仍然存在

#### 1.2、左右极限
 - 左极限：x -> a- (x 从小于a的方向趋近a)
 - 右极限：x -> a+ (x 从大于a的方向趋近a)
 - 函数极限存在的充要条件： $\lim_{x \to a-} f(x) = L$ 且 $\lim_{x \to a+} f(x) = L$
  
#### 1.3、精确定义
 - 对于任意ε > 0, 存在δ > 0, 使得当 0 < | x - a | < δ 时，有 | f(x) - L | < ε。

#### 2.1、方法一：直接带入（首选）
#### 2.2、方法二：因式分解（0/0）
#### 2.3、方法三：有理化（带根号）
#### 2.4、方法四：抓大头（x -> ∞ 时）

#### 2.5、方法五：两个重要极限
  1. $\lim_{\square \to 0} \frac{\sin \square}{\square} = 1$
  2. $\lim_{x \to \infty} (1 + \frac{1}{x})^x = e$ 或 $\lim_{x \to 0} (1 + x)^{1/x} = e$

#### 2.6、方法六：等价无穷小替换（简便但需谨慎）
- 当x->0时，sinx∼x,tanx∼x,arcsinx∼x,arctanx∼x，ln(1+x)∼x, $e^x - 1 \sim x$，$1 - \cos x \sim \frac{x^2}{2}$
- 注意：只能在乘除法中替换，加减法中慎用（易出错）

#### 2.8 方法八： 洛必达法则（导数）
- 若极限为 0/0， ∞/∞， 则limf（x）/ g（x）= lim $f'(x)$ / $g'(x)$
- 可重复使用
  
### 三、无穷小与无穷大
#### 3.1 无穷小
- 极限为 0 的变量, 例，x->0时，x， sinx，1-cosx都是无穷小

#### 3.2 无穷大
- 绝对值无限增大

#### 3.3 无穷小比较
- 高阶：a / b -> 0 ，a = 0（b）
- 同阶：a / b -> $c \neq 0$
- 等价：a / b -> 1 , a ~ b
  
### 四、连续性与极限的关系

#### 4.1 连续的定义
- $\lim_{x \to a-} f(x) = f(a)$
- 三个条件：f(a) 有定义 & 极限存在 & 极限值等于函数值
  
#### 4.2 间断点分类
- 可去间断点：左右极限存在且相等，但不等于函数值
- 跳跃间断点：左右极限存在但不相等
- 无穷间断点：左右极限至少一个为无穷
- 振荡间断点: 左右极限不存在
